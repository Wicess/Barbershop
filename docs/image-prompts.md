# Image prompts: Barbershop Manager (Cameroon edition)

There are 26 photos in the app. Each prompt below is complete: the shared style
(Cameroon, real dark skin, **bright daylight**, light backgrounds, fresh true
colours) and the rules (no text, no logos, real hands) are already built in.
Paste one prompt per image, generate 3–4 and keep the most natural one.

All the photos are **bright and airy on purpose**: the app's cards and Home slides
already add their own dark shading where text sits, so dark photos would make the
whole app look gloomy. If a result still comes out dark, add "brighter, high-key,
more daylight" and generate again.

| Kind | Shape to generate | The app shows it at |
|---|---|---|
| Service and drink photos (22 of them) | 4:3 landscape | 480×360 |
| `hero-shop` | 3:2 landscape | 960×640 |
| `hero-dark` | 2:3 portrait | 900×1400 |
